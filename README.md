# استودیوی عکس مد ۳:۴ (Fashion Studio 3:4)

ابزار تحت وب تخصصی، مستقل و کاملاً درون‌مرورگری برای آماده‌سازی، برش استاندارد ۳:۴، تفکیک پس‌زمینه و بهینه‌سازی عکس‌های پوشاک و مدلینگ فروشگاه‌های اینترنتی.

## ویژگی‌های کلیدی
- **پردازش ۱۰۰٪ محلی در مرورگر:** بدون نیاز به سرور، دیتابیس یا کلید API؛ کلیه عملیات روی سخت‌افزار رایانه کاربر انجام می‌شود و تصاویر به هیچ سروری ارسال نمی‌شوند.
- **نسبت تصویر دقیق ۳:۴ (پرتره مد):** کادربندی هندسی بدون هیچ‌گونه کشیدگی یا دفرمگی پیکسل‌ها.
- **تشخیص هوشمند مدل و لباس:** پیشنهاد کادر بهینه با تمرکز بر لباس و چهره؛ امکان انتخاب بین چند مدل در صورت وجود چند نفر در تصویر.
- **حذف پس‌زمینه اختیاری:** انتخاب بین پس‌زمینه سفید استودیویی یا کاملاً شفاف با لبه‌های نرم.
- **تنظیمات رنگ و نور:** اصلاح ملایم خودکار، تنظیم دستی روشنایی، کنتراست، اشباع و دمای رنگ؛ دارای دو سبک رنگی «طبیعی» (تضمین نمایش رنگ واقعی پارچه) و «بهبودیافته».
- **پشتیبانی از فرمت‌های HEIC و JPG:** رمزگشایی مستقیم تصاویر آیفون (HEIC/HEIF) در مرورگر.
- **فشرده‌سازی WebP زیر ۲۰۰ کیلوبایت:** حذف کامل فراداده‌های دوربین و GPS؛ پیشنهاد خودکار دو حالت «زیر ۲۰۰ کیلوبایت» و «کیفیت بالا» برای تصاویر بسیار حجیم.

## راهنمای اجرای محلی (توسعه)
برای اجرای پروژه روی سیستم شخصی:

```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. اجرای سرور توسعه محلی
npm run dev
```

سپس در مرورگر خود آدرس `http://localhost:3000` را باز کنید.

## راهنمای ساخت نسخه نهایی و انتشار روی هاست وب (Static Build)
این نرم‌افزار به صورت استاتیک بیلد می‌شود و به هیچ سرور Node.js فعالی نیاز ندارد.

### ۱. دستور ساخت بیلد نهایی:
```bash
npm run build
```
پوشه‌ای به نام `dist` ساخته می‌شود که حاوی تمام فایل‌های HTML، CSS و JS نهایی است.

### ۲. آپلود روی هاست اشتراکی (cPanel / DirectAdmin):
1. وارد کنترل‌پنل هاست خود شوید.
2. به بخش **File Manager** بروید.
3. تمام محتویات داخل پوشه `dist` را مستقیماً درون پوشه `public_html` دامنه یا ساب‌دامنه خود آپلود فرمایید.

### ۳. استقرار روی Nginx / Apache:
محتویات پوشه `dist` را در مسیر ریشه وب سرور (مثلاً `/var/www/fashion-studio`) قرار داده و پیکربندی زیر را در بلاک سرور Nginx اعمال کنید:
```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

### ۴. استقرار روی هاست‌های ابری (لیارا، Vercel، Netlify):
در زمان ایجاد برنامه، نوع آن را **برنامه استاتیک (Static HTML)** انتخاب کرده و پوشه خروجی را `dist` تعیین کنید.
